# Skull King Companion

스컬킹 보드게임을 위한 안드로이드 점수 기록 앱입니다. 첫 버전은 플레이어별 누적 점수와 라운드별 입찰·획득 트릭을 기록합니다.

## 현재 기능

- 플레이어 추가
- 라운드별 입찰과 획득 트릭 기록
- 스컬킹 기본 점수 규칙 자동 계산
  - 정확히 맞춘 0 입찰: `라운드 × 10점`
  - 정확히 맞춘 양수 입찰: `입찰 × 20점`
  - 실패: 차이 1개당 `-10점`
- 누적 점수와 라운드 기록 확인

## 실행

Android Studio에서 이 폴더를 열어 Gradle 동기화 후 실행하세요. JDK 17이 필요합니다.
