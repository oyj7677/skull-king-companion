# 완료된 게임 결과는 새 게임을 시작할 때까지 유지한다

마지막 라운드가 확정된 뒤 Active Game은 Completed Game이 되고 결과 화면을 계속 표시한다. 별도의 과거 게임 목록은 만들지 않으며, 사용자가 새 게임 시작을 확인했을 때만 기존 게임을 교체한다.

## Considered Options

- 완료 즉시 게임 삭제: 테이블에서 최종 순위와 점수를 다시 확인할 수 없다.
- 여러 과거 게임을 보관: v1의 단일 게임 범위를 넘어서 게임 선택·목록·삭제 흐름이 필요하다.

## Consequences

- Completed Game은 앱을 다시 열어도 결과 화면으로 복구된다.
- 새 게임 시작은 기존 게임을 대체한다는 확인 단계를 거친다.
