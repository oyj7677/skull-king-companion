# 점수 규칙은 게임별 설정으로 둔다

점수 규칙과 Round Schedule은 앱 전체에 고정하지 않고 Active Game을 시작할 때 선택하는 설정으로 보관한다. 기본 점수만 쓰는 게임과 특수 카드 보너스를 쓰는 게임 모두를 지원하되, 기록된 점수의 해석이 바뀌지 않도록 게임 도중에는 설정을 변경하지 않는다.

## Considered Options

- 앱 전체에 하나의 규칙만 두기: 구현은 단순하지만 서로 다른 모임의 규칙을 수용할 수 없다.
- 점수마다 개별 보정값 입력: 유연하지만 계산 근거와 게임 규칙이 추적되지 않는다.

## Consequences

- 게임 설정 화면에서 Rule Set을 선택·구성한다.
- 게임 설정 화면은 기본 10라운드와 함께 총 라운드 수를 선택하게 한다.
- 각 점수 기록은 그 게임의 Rule Set을 사용한다.
- v1에서 설정 변경은 새 게임을 시작할 때만 가능하다.
