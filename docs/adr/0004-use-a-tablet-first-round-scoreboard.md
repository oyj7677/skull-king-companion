# 라운드 점수 입력은 태블릿 우선의 한 화면 점수판으로 구성한다

v1의 주 사용 환경은 게임 테이블 위의 태블릿이다. 모든 플레이어의 입찰, 획득 트릭, 추가점수, 라운드 점수를 같은 화면에서 확인·입력하고 한 번에 라운드를 확정한다.

## Considered Options

- 플레이어 한 명씩 순차 입력: 작은 휴대폰 화면에는 단순하지만, 누락 확인과 라운드 전체 검토에 여러 번의 전환이 필요하다.

## Consequences

- 가로 태블릿 화면에서 플레이어별 한 행을 사용한다.
- 열은 플레이어, 입찰, 획득, 추가점수, 라운드 점수로 고정한다.
- 점수판은 2명에서 최대 8명의 플레이어 행을 한 화면에 표시한다.
- 라운드를 저장하기 전 모든 플레이어 행이 완료됐는지 한 화면에서 확인한다.
