# v1은 진행 중인 게임 하나만 기록한다

v1은 한 기기에서 활성 게임 하나를 기록하는 데 집중한다. 여러 게임을 저장·재개하는 기능보다 테이블에서 빠르게 점수를 남기고 게임 결과를 보는 흐름을 우선하기로 했다.

## Considered Options

- 여러 게임을 저장하고 선택하는 구조: 이후 확장성은 좋지만, v1의 화면·데이터 모델·복구 흐름을 불필요하게 넓힌다.

## Consequences

- v1은 하나의 Active Game만 생성·수정·완료할 수 있다.
- 여러 게임 저장은 향후 데이터 이전을 포함하는 별도 결정으로 다룬다.
