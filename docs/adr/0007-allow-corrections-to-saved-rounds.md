# 저장된 라운드는 수정할 수 있다

테이블에서 발생할 수 있는 기록 오류를 바로잡을 수 있도록, 확정된 Round도 편집할 수 있게 한다. 편집이 저장되면 그 Round의 점수와 이후 누적 점수, Completed Game의 결과를 즉시 다시 계산한다.

## Considered Options

- 라운드 확정 뒤 수정 금지: 점수판의 단순성은 높지만, 기록 실수를 고치려면 게임을 다시 시작해야 한다.

## Consequences

- 결과 화면에서도 각 Round의 기록을 열어 수정할 수 있다.
- 점수는 저장된 합계를 수정하는 대신 입찰·획득 트릭·Round Bonus로 다시 계산한다.
- 수정 저장은 라운드 기록과 누적 결과를 한 번에 일관되게 갱신한다.
