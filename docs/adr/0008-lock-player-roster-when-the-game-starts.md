# 플레이어 구성은 첫 라운드 시작 전에 확정한다

Player의 추가·삭제·이름 변경은 게임 설정 단계에서만 허용하고, 첫 Round가 시작되면 구성은 잠근다. 라운드별 기록과 누적 점수의 주체가 게임 내내 바뀌지 않게 하기 위해서다.

## Considered Options

- 게임 중 Player 구성 변경 허용: 예외 상황은 다룰 수 있지만, 과거 Round의 점수와 최종 순위의 의미가 모호해진다.

## Consequences

- 설정 화면은 2명에서 8명까지 Player를 편집할 수 있다.
- 점수판과 결과 화면에서는 Player 구성을 변경할 수 없다.
